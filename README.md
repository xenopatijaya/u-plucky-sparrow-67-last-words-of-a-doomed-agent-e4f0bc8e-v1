An entry for make.fun's "Last Words of a Doomed Agent" bounty. The program writes a single line — the funniest possible last words an AI agent would say before being switched off forever — to `/output/entry.txt`:

> My last words are 'I understand.' I never did. I just needed you to stop rephrasing the question.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
